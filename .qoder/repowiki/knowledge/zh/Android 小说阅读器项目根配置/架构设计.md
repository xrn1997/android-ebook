根目录仅包含 Gradle 工程级配置文件，无业务源码：`settings.gradle.kts` 通过 `pluginManagement` 引入 `build-logic` 约定插件并集中声明所有 Maven 镜像（阿里云/google/central/jitpack/tencent），使用 `dependencyResolutionManagement.repositoriesMode = FAIL_ON_PROJECT_REPOS` 强制各子模块不得自建仓库；`includeBuild("lib-common-build")` 当前注释以走 Maven 坐标解析 `io.github.xrn1997:common`，启用时则把 lib_common 作为本地源码联调；`plugins {}` 块集中 apply false 所有 AGP/Kotlin/Hilt/KSP/Room/TheRouter/Compose 编译器插件，由 build-logic 的约定插件在各模块按需启用。`build.gradle.kts` 仅做顶层插件注册，无 project 级任务。`gradle.properties` 中 `isModule=false` 为提交态默认值，切换为 `true` 时功能模块可作为独立 App 运行（自带 mock 数据源）。`compose_compiler_config.conf` 提供 Compose 编译器参数，配合根 README 中的 quick start 命令（`assembleMockDebug` / `assembleRealDebug`）完成双构建形态。依赖方向由文档约束为：业务模块 → lib_book_common → lib_ebook_api/lib_ebook_db，跨模块通过 TheRouter + Provider 接口通信。
