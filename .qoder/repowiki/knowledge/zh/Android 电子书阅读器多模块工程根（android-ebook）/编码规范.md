- 依赖版本与插件 ID 集中维护于 `gradle/libs.versions.toml`，子模块统一通过 `alias(libs.xxx)` 引用，禁止硬编码版本。
- 所有 Android 模块的构建配置（AGP/Kotlin/Compose/Hilt/Room/Lint）一律通过 `build-logic` 的 `xrn1997.*` convention plugins 接入，不在子模块自建 gradle block。
- 跨模块通信不直接依赖对方代码，统一使用 TheRouter 路由与 lib_book_common 暴露的 Provider 接口。
- Mock/Real 数据源通过 product flavor (`mock` / `real`) 和 source set (`src/mock/`、`src/real/`) 双源开关，业务代码只依赖抽象 DataSource 接口。
