本模块以 `com.ebook.common` 命名空间暴露跨功能模块可复用的通用能力，按职责划分为若干子包：
- `analyze/source/` 定义网络书源解析接口契约（`BookParser`、`BookSourceManager`），内置基于 Jsoup 的默认实现（`JsoupBookParser`）并加载 assets 中 `default_sources.json` 作为默认书源规则。
- `di/` 集中声明 Hilt 模块（`AnalyzeModule`、`SessionModule`），通过 `@Binds` 将 `UserSessionManager`、`TokenRefresher`、`BookSourceManager` 等接口绑定到具体实现。
- `domain/` 存放纯 Kotlin 领域类型与会话管理抽象（`UserSession`、`UserSessionManager`、`AndroidUserSessionManager`、`SessionTokenRefresher`），其中 `UserSessionManager` 仅依赖 StateFlow、不耦合 Android。
- `repository/` 与 `manager/` 分别封装 Profile 信息（头像/昵称）与书架操作，状态统一以 `StateFlow` 暴露给 UI。
- `ui/` 收敛共享 Compose 组件（`BookCover`、`CommonUiComponents`、`CommonPainters`、`CommonUiTokens`）。
- `interceptor/` 提供 TheRouter 拦截器 `LoginInterceptor`，在页面跳转时按需重定向至登录页。
- `util/` 提供 SP 工具与日期工具，`event/` 集中跨模块常量（KeyCode、路由路径、缓存 key）。
依赖方向严格遵循：业务模块 → lib_book_common → lib_ebook_api（网络/HTTP）→ lib_ebook_db（Room 实体）；模块自身被所有 `module_*` 依赖且不相互依赖。构建产物由 Gradle Android Library 插件产出 AAR，KSP + Dagger/Hilt 生成工厂类，Assets 中附带默认书源 JSON 随包分发。
