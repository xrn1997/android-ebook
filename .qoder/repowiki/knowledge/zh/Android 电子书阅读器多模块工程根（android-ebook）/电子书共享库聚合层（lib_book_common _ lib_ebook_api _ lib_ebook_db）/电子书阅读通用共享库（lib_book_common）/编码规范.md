- 公共 API 以 Kotlin 接口形式暴露（如 `BookParser`、`BookSourceManager`、`UserSessionManager`），具体实现集中在 `impl` 后缀文件并通过 Hilt 的 `@Module` + `@Binds` 绑定，调用方仅依赖接口。
- 可变状态统一通过 `MutableStateFlow` + `asStateFlow()` 对外暴露，配合 `BaseModel`（来自 lib_common）统一管理协程作用域。
- SharedPreferences 访问一律经 `SPUtil` 单例，键名集中定义在 `event/KeyCode` 或类似常量文件下，禁止硬编码字符串 key。
- 跨模块共享的 Compose 组件放入 `ui` 包并使用 `CommonUiTokens` 中的设计令牌（圆角、间距、颜色等），避免在各业务页重复组合相同的装饰逻辑。
- 需要 Android 上下文或系统服务的能力与纯领域逻辑解耦：接口位于 `domain/`（无 Android 依赖），实现放在同包下的 `Android*` 类（如 `AndroidUserSessionManager`），通过 Hilt SessionModule 注入。
- 路由层面的鉴权逻辑集中在 `LoginInterceptor` 中，通过 TheRouter 的 `RouterReplaceInterceptor` 在跳转前检查登录态并重定向，不在目标页面内重复判断。
