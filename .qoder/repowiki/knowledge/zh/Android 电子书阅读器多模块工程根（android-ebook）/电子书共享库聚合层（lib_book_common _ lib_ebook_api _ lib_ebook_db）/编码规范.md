- 三子模块均使用约定的 `xrn1997.android.library`/`hilt`/`room` 插件并通过 `gradle/libs.versions.toml` 管理依赖版本，禁止硬编码版本号。
- 对外公开 API 以 `api()` 暴露给下游（如 `lib_book_common` 向 `module_*` 透出 UI 组件与 domain 类型，`lib_ebook_api` 对 Retrofit 实体用 `api(libs.common)`），内部实现统一用 `implementation()` 隔离。
- 所有运行时单例（DB、SessionManager、Repository）均通过 Hilt `@Module` + `@Provides`/`@Singleton` 装配，业务侧只 `@Inject` 构造器参数，不再手写单例。
- 网络请求统一经 Retrofit Service + `CoroutineAdapter` 封装 suspend 接口，响应走 `RespDTO` 信封并由 `AuthInterceptor` + `@AuthAllowedHosts` 处理 token；书源请求必须改用 `@Named("source")` 纯净客户端以避开认证头。
