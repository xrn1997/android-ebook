模块按包 `com.ebook.db` 组织：`entity/` 存放 Room `@Entity` 数据模型（`BookShelfEntity`、`BookInfoEntity`、`ChapterListEntity`、`SearchHistoryEntity`、`DownloadChapterEntity`、`BookGroupEntity`）以及若干不在数据库中的内存传输模型（如 `LibraryEntity`、`SearchBookEntity`、`WebChapterEntity`、`WebContentEntity`）；`dao/` 为每张表提供 `@Dao` 接口，所有写操作统一用 `OnConflictStrategy.REPLACE` 实现 upsert 语义，读操作暴露同步方法或 `Flow<T>` 响应式变体（如 `getAllBooks` / `getAllBooksFlow`、`observeRemainingCount`）；`AppDatabase.kt` 通过 `@Database(entities, version=4, exportSchema=true)` 集中声明六个实体，并暴露对应的 DAO 抽象方法；`di/DatabaseModule.kt` 以 Hilt `@Module` + `@InstallIn(SingletonComponent::class)` 提供 `AppDatabase` 单例与各 DAO 实例，使用 `BundledSQLiteDriver()` 驱动，并在 `addMigrations` 中串接 `MIGRATION_1_2`→`MIGRATION_2_3`→`MIGRATION_3_4` 三版增量升级脚本；依赖方向严格自上而下（业务模块 → lib_book_common → 本库），本库不引用任何业务模块，仅被仓库其他模块消费。
