- 每个网络能力以 `XxxDataSource` 接口定义契约，再由 `XxxNetwork : XxxDataSource` 实现并通过 Hilt @Singleton 暴露，便于独立测试替换为 `XxxNetworkTest` mock。
- 实体类一律使用 kotlinx-serialization 的 `@Serializable` 标注，并以 `@SerialName` 将客户端内部字段名映射到服务端蛇形 JSON 键值，禁止开启全局命名策略。
- 所有远端地址拼装统一走 `API.URL_HOST_*` + `API.URL_PORT_*`，禁止在任何 Network 中硬编码主机或端口。
- Release 类网络操作通过 `CoroutineAdapter.safeApiCall` 包装，统一处理 IO 线程切换、`RespDTO.code` → `Result` 转换以及 A0230 静默刷新重放，不在业务类内重复判断 code。
- 不同用途的 OkHttpClient 通过 Hilt `@Named` 区分：带认证的共享客户端走 `AuthAllowedHosts` 白名单，第三方书源用 `@Named("source")`、GitHub Release 用 `@Named("release")`，均不携带 Authorization 头。
- 跨模块可替换的异步能力（如 `TokenRefresher`、`UserDataSource`）以接口定义在 `lib_ebook_api`，具体实现由上层模块经 Hilt @Binds 注入，避免 lib_ebook_api 反向依赖业务模块。
