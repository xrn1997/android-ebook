三层依赖方向固定：`module_*` → `lib_book_common` → (`lib_ebook_api` + `lib_ebook_db`)，`lib_ebook_db` 不反向依赖其它两方。
- 装配契约：三个子模块各自通过 Hilt 暴露 `@Module`/`@Provides`（`SessionModule`、`ContentStoreModule`、`TransactionModule`、`AnalyzeModule`），由 `lib_book_common` 统一注册到应用级 `@HiltApplication`，使业务模块仅感知 `com.ebook.common.*` 这一包名。
- 领域数据契约由 `lib_ebook_api`（Retrofit 实体、服务接口）与 `lib_ebook_db`（Room 表、DAO）共同定义，再由 `lib_book_common` 的 `repository/*` 通过 DAO 拼装成上层可用的 Repository；跨层共享类型（BookComment 等）放在 `domain/` 避免业务模块直触 Retrofit/Room 实现细节。
- 运行时环境差异通过 `buildConfigField` 注入：`lib_ebook_api` 把 `ebook.server.host` 从根目录 `local.properties` 编译进 `BuildConfig.EBOOK_SERVER_HOST` 作为所有后端请求基址；`lib_book_common` 通过 `IS_DEBUG` 在调试态开启日志/覆盖层开关。
- 测试统一以 Robolectric + Room InMemory DB 跑 DAO 与需真实 SharedPreferences 的 SessionManager，确保各子模块在无设备条件下即可验证数据通路。
