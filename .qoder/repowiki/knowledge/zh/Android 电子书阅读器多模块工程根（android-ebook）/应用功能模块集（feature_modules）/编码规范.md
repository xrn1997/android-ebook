- 各业务模块以 Android Library 形式发布，对外仅通过 TheRouter Provider 暴露接口，避免直接互相 import 业务类
- 依赖注入统一使用 Hilt，模块级配置以 @Module + @InstallIn(SingletonComponent::class) 声明，由上层 Application 合并
- UI 一律采用 Jetpack Compose 编写，ViewModel 通过 hilt-androidx 注入并在 Activity/Fragment 或 Composable 中消费
- 跨模块可替换的底层实现（如网络请求）通过 Provider/Retrofit 抽象 + flavor 源码集（real/mock）解耦
