本层是 Android 应用的 feature 分层，由 module_app 作为宿主与 Hilt 根组件注入点，module_main 提供 SplashActivity/MainActivity 启动流程及 Compose 导航容器；四个业务模块（book/find/me/login）以独立 Android Library 形式存在，各自通过 TheRouter Provider（如 `provider()`）暴露跨模块访问能力，被其它模块或 main_shell 通过路由字符串触发；依赖注入统一走 Hilt：每个业务模块以 `@Module` + `@InstallIn(SingletonComponent::class)` 注册自身依赖，再由 app_entry 中定义的 Application Hilt 根组件装配。flavor 维度由 module_app 的 real/mock 双网络构建变体向上辐射，各功能模块通过相同 build.gradle sourceSet 结构复用测试数据与 mock 实现，确保同一套 UI 逻辑在不同网络后端下运行一致。
