本模块为独立的 Android 组件库（构建于 xrn1997.android.component 约定插件之上），支持 isModule=false（作为 library 被 module_app 依赖）与 isModule=true（独立可运行 App，走 src/main/module/AndroidManifest.xml）两种集成方式。内部按职责划分三个子包：
- `provider/`：TheRouter SPI 实现 `MeProvider`，通过 `@ServiceProvider` 暴露 Compose 页面，供宿主 NavHost 组合，避免跨模块直接依赖。
- `mvvm/viewmodel/`：基于 lib_common 的 `BaseViewModel` / `NoOpModel` 实现的页面状态容器，使用 StateFlow + combine/stateIn 管理多数据源状态（如 MePageViewModel 合并用户会话、个人资料、书架统计）。
- `view/` 与 `view/profilePhoto/`：Activity 统一继承 lib_common 的 `BaseMvvmActivity`，通过 Hilt 的 `HiltViewModel` 注入 ViewModel；每个页面在集成态清单中集中声明。

依赖方向单向向内：仅依赖 `:lib_book_common`、`:lib_ebook_api`、`libs.common`、Router、Coil 以及 hilt-navigation-compose，不反向依赖其他业务模块，遵循「业务模块 → 共享库」的分层约束。路由跳转经 TheRouter（`KeyCode.Me.SETTING_PATH` 等），版本更新检查逻辑由模块自身持有（见 ADR-0021）。测试以 JUnit 单元与 `src/main/test/debug` mock source set（独立运行时替换网络源）完成。
