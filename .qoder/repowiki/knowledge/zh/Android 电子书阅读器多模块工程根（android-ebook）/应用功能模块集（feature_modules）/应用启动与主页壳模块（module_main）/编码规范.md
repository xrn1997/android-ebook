- 页面以 Compose 的 sealed class 枚举主页 Tab（如 `Screen`），配合 Compose Navigation + TheRouter 完成跨模块跳转。
- 所有 Activity/Fragment 统一通过 Hilt `@AndroidEntryPoint` + KSP 生成 `*_GeneratedInjector` 进行成员注入，不在类中手写构造。
- 清单文件遵循双源替换约定：集成与独立模式分别维护两份 `AndroidManifest.xml`，两处必须同步保持声明一致。
- 模块级依赖版本全部经由 Gradle version catalog (`libs.xxx`) 引用，脚本中禁止出现字面值版本号。
