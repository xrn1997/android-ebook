该模块为可独立运行的 Android Component（通过 build-logic 的 `xrn1997.android.component` 与 `xrn1997.android.compose` 约定插件配置），namespace 为 `com.ebook.main`，依赖方向单向指向 `lib_book_common`（书籍领域 UI/Provider 接口）。

从构建产物可见源码结构：
- 入口层：`SplashActivity`（应用启动页，配合 `androidx.core:core-splashscreen`）、`MainActivity`（主界面宿主）。两者均通过 Hilt/KSP 生成 `*GatedInjector` 注入。
- 导航层：`Screen` sealed class 定义 `{Bookshelf, Bookstore, Me}` 三个主页 Tab 路由条目，由 Compose Navigation + TheRouter 组合；TheRouter 在编译期扫描 `@Route` 注解生成 `RouterMap__TheRouter__*.kt`，并在 `assets/therouter/routeMap.json` 中固化。
- 依赖注入：启用 KSP 并声明 `dagger.compiler` 依赖，Hilt 用于 Activity/ViewModel 成员注入；跨模块 Provider 页面按约定通过 TheRouter 创建而非 Hilt，页面内 ViewModel 再经 Hilt 注入。
- Manifest 切换：依赖方采用 source set 替换（集成态 `src/main/AndroidManifest.xml` vs 独立态 `src/main/module/AndroidManifest.xml`），确保两种模式下的 Activity/权限一致。

本模块不持有业务逻辑，仅负责启动流程、Tab 导航壳与横切装配。
