- 跨模块共享页面以 `@Composable () -> Unit` 形式通过 TheRouter 的 `@ServiceProvider` + `IBookProvider` 暴露，宿主通过 NavHost 直接组合而非 Intent 跳转。
- 持有状态的页面统一继承 `BaseMvvmActivity`，使用 `hiltViewModel()`（Compose 版本）获取 ViewModel，并通过基类 `MvvmBinder` 的命令通道进行 Toast/Finish/Navigate，不直接处理 UI 副作用。
- UI 状态使用 `mutableStateOf` 与 Flow 配合 `collectAsState` 驱动 Compose 重建，ViewModel 负责数据流而页面只做状态展示。
- 网络/书源请求使用 Kotlin Coroutines + Flow 异步；禁止引入 RxJava3，所有响应式交互已迁移至协程。
- 日志统一通过 lib_common 的 `Logger` 输出，禁止直接使用 `android.util.Log`。
- 主题与全局 UI 常量走 lib_common 提供的 `AppTheme`、`CommonUiTokens`、`CommonListItem`、`BookCover` 等共享组件，模块内不得重复实现设计令牌。
