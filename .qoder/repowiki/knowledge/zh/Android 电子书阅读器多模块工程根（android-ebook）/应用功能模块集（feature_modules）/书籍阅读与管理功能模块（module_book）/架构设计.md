本模块命名空间 `com.ebook.book`，通过统一约定插件 `xrn1997.android.component` 作为可插拔的功能模块被 `module_app` 依赖；对外只通过 TheRouter 暴露路由与 Provider 接口。

- **入口与页面层**：`BookShelfPage`、`BookDetailActivity`、`BookCommentsActivity`、`ImportBookActivity`、`ReadBookActivity`、`DownloadManageActivity` 为业务入口，继承 lib_common 的 `BaseMvvmActivity`，按约定把 ViewModel 注入并通过基类命令通道下发提示/导航/finish。
- **跨模块集成**：通过 `@ServiceProvider` 的 `BookProvider : IBookProvider`，将 `mainBookPage: @Composable () -> Unit = { BookShelfPage() }` 交由宿主 NavHost 直接组合，避免 Activity 跳转耦合。
- **MVVM 层**：`mvvm/viewmodel/` 下各 ViewModel 继承 `BaseViewModel`/`BaseRefreshViewModel`，状态用 Flow + `collectAsState` 驱动 Compose UI，事件与副作用集中放在 VM（如书架刷新、章节下载、评论增删）。
- **仓库/存储层**：`repository/` 仅聚合 Room DAO 与网络/书源能力，由 VM 调用；下载任务队列持久化在 Room `download_chapter` 表。
- **前台服务**：`service/DownloadService` 是独立的 `foregroundServiceType="dataSync"` 前后台服务，通过 Intent 动作（启动/暂停/恢复/取消）通信，失败章出队并计数，通知常驻并上报进度到 `DownloadRepository.downloadState`。
- **阅读器子系统**：`reader/` 封装翻页（`ReaderPagerController`）、布局缓存（`ChapterLayoutCache`）、面板（章节列表抽屉、字体/亮度/更多设置、章节下载弹窗）、排版器（`ReaderTypesetter`），整片豁免系统深色主题以维持阅读一致性。
- **依赖方向**：单向依赖 `lib_book_common`（领域模型、通用 UI、书源解析、内容存储接口）以及 `lib_ebook_db`（Room 实体/DAO）；不反向依赖其他业务模块。TheRouter KSP 生成 `*__TheRouter__Autowired.kt`，Dagger/KSP 生成 Hilt modules 与 `GeneratedInjector`。
