本模块为 AGP Android library（namespace `com.ebook.find`），按 MVVM + Jetpack Compose 组织：`entity/` 存放 DTO（如 `BookType`）；`mvvm/viewmodel/` 提供 `SearchViewModel`、`ChoiceBookViewModel`、`LibraryViewModel`，均通过 Hilt/KSP 生成 Factory；`repository/` 包含 `SearchHistoryRepository`、`BookSourceRepository` 以协程封装数据层；`page/` 提供 Composable 页面（如 `BookstorePage`），由 TheRouter Provider（`provider/FindProvider`）暴露给主导航组合；`view/` 放置 Compose 复用 UI 片段（如 `SearchBookItem`）。构建配置声明依赖 `lib_book_common`（统一基类/Theme/组件）、Retrofit/Rx 栈的 lib_ebook_api（间接）、TheRouter（`libs.router`）进行跨模块路由、Coil 做图片加载，并使用 Hilt Navigation Compose 支持 Compose 内的 ViewMode 注入；两个入口 Activity（`ChoiceBookActivity`、`SearchActivity`）在各自 Manifest 中注册，通过 @Route 被 module_main 引导。
