- MVVM 分层清晰：entity → repository → mvvm/viewmodel → page/Provider，页面通过 TheRouter Provider 暴露 Composable 而非 Fragment。
- ViewMode 一律通过 Hilt/KSP 生成类并以 `hiltViewModel()` 注入，不手动 `by viewModels()`。
- 跨模块通信采用 TheRouter 路由与服务提供者，避免功能模块间直接 project 依赖。
- UI 使用 Jetpack Compose，图片加载统一走 Coil（Compose API）。
- 权限与清单裁剪遵循 ADR-0022，仅声明该业务真正需要的网络相关权限，相机等特征声明交由 module_app。
