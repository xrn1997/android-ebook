模块以 `com.ebook.login` 为根包，遵循 MVVM + Coroutines + Flow 的分层组织：
- `mvvm/viewmodel/`：三个页面级 `@HiltViewModel`（`LoginViewModel`、`RegisterViewModel`、`ModifyPwdViewModel`），均继承 lib_common 的 BaseViewModel，封装一次性命令（如 sendCode、login、register）并管理页面状态。
- `repository/UserRepository.kt`：认证数据层聚合 UserDataSource（email/code/password 等端点），统一通过 CoroutineAdapter.safeApiCall 包装为 Result，会话过期由网络层静默处理；模块在独立运行时通过 Hilt EntryPoint (`UserRepositoryEntryPoint`) 配合 Provider 桥接 TheRouter 注入。
- provider/LoginProvider：实现跨模块共享的 `ILoginProvider` 接口，让主模块不直接依赖 login 模块的业务类，仅持有可组合的登录入口。
- UI 层为四个 `BaseMvvmActivity`（Login/Register/VerifyUser/ModifyPwd），全部使用 Compose + Material3 构建表单；其中 LoginActivity 声明 `singleTask` launchMode 并以 onNewIntent 消费预填邮箱，解决单例复用场景下 LaunchedEffect 不重跑导致的参数丢失问题。
- 导航经 TheRouter `@Route(path = KeyCode.LOGIN.*_PATH)` 注册路由路径，页面间跳转统一走路由或显式 startActivity。
- 独立运行模式通过替换清单文件（`src/main/module/AndroidManifest.xml`）启用，挂载 `debug.TestApplication` 与 debug 宿主 Activity，自动编译 `src/main/test/debug/` 下的 MockNetworkModule 实现 mock 数据源。
- 模块依赖方向单向向外：仅依赖 `lib_book_common`（MVVM 基类、Compose 工具、事件常量）与 `lib_ebook_api`（UserDataSource、网络实体），互不依赖其他业务模块。
