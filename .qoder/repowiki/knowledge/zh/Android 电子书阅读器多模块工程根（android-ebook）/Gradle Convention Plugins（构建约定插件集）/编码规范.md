- 所有对外暴露的 Gradle 插件均以 `xrn1997.` 命名空间前缀（如 `xrn1997.android.application`、`xrn1997.hilt`），在 `gradlePlugin {}` 块中以字符串字面量从版本目录拉取 ID。
- 每个约定 Plugin 文件对应一个 `*ConventionPlugin : Plugin<Project>` 类，`apply()` 中使用 `with(target)` 包裹并以 `apply(plugin = ...)` + `extensions.configure<T>()` 分步装配。
- 重复的编译期选项（minSdk/targetSdk compileSdk Java/Kotlin version、warningsAsErrors、coreLibraryDesugaring）抽取到 `com.xrn1997.convention` 包内的同名 `configureXxx` 扩展函数供各 Plugin 复用。
- 版本与三方依赖一律经 `libs.findLibrary(...)` 从版本目录解析，构建脚本内不出现硬编码版本号。
- 对可选能力（如 KSP/Kotlin-JVM/Hilt）使用 `pluginManager.withPlugin("...")` 条件注册，避免在非 Android/JVM 工程中触发不可用依赖。
- 测试相关配置（Junit、AndroidInstrumentedTests、打印 APK task、动画禁用等）作为独立扩展放在 `com.xrn1997.convention` 包，由多个 Plugin 调用而非复制。
