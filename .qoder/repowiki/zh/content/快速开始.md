## 简介
本指南面向首次参与本项目的新开发者，帮助你在最短时间内完成环境准备、依赖安装、构建与运行。项目为 Android 电子书阅读器，采用 MVVM + 多模块架构，界面全部基于 Jetpack Compose；提供 mock（内存数据源，无需后端）与 real（连接真实后端）两种构建形态，便于无后端环境下完整调试。

## 环境要求
- Android Studio：>= 2025.1.3（低版本无法兼容当前 Gradle）
- JDK：17（使用 Android Studio 自带的 JBR 即可）
- Gradle / AGP：Gradle 9.4.1 / AGP 9.2.1（由 Gradle Wrapper 自带，无需本地安装）
- 目标设备：compileSdk/targetSdk 37，minSdk 26（Android 8.0+）
- 工具链：AGP 内置 Kotlin（无需额外配置），KSP 增量编译已启用

## 环境搭建步骤
1) 克隆仓库
- 使用 SSH 或 HTTPS 将仓库克隆到本地工作目录。

2) 打开项目
- 使用 Android Studio 打开根目录，等待索引完成。IDE 会自动根据 Gradle Wrapper 下载 Gradle 9.4.1 并拉取依赖。

3) SDK 与工具链
- 确保已安装 API 37（targetSdk）及 Android 8.0+ 的模拟器或真机。
- JDK 使用 Android Studio 自带的 JBR（满足 JDK 17）。
- 如网络受限，可参考 settings 中配置的镜像源（阿里云等），以便在干净环境中顺利同步。

4) 首次同步
- 执行一次 Gradle 同步，确认无解析错误。若失败，优先检查网络与代理设置。

## 构建与运行（两种模式）
项目通过 product flavor 提供两种构建形态：
- mock：内存数据源，开箱即用，无需后端
- real：连接真实后端服务器

常用命令（Windows 用户在 PowerShell 中使用 .\gradlew 替代 ./gradlew）：
- 构建并安装 mock 调试包：./gradlew :module_app:assembleMockDebug
- 构建并安装 real 调试包：./gradlew :module_app:assembleRealDebug

说明：
- 两种形态均由 module_app 产出，applicationId 不同（mock 带后缀）
- 调试时可直接在 IDE 中选择对应的 Build Variant 进行运行

## 本地配置（local.properties）
- 后端基址通过 local.properties 的 ebook.server.host 注入，缺省值为 10.0.2.2（模拟器访问宿主机地址）
- 局域网真机调试时，改为宿主机的 IP 地址
- 若使用 adb reverse 或本机回环地址（如 127.0.0.1），请确保服务端口可达且符合系统限制

注意：
- Android 17（targetSdk 37）起对“本地网络”访问有权限限制，本项目不申请相关运行时权限；建议使用 adb reverse 配合 127.0.0.1，或使用公网 IP，避免权限问题导致请求失败。

## 独立模块开发模式
当 gradle.properties 中 isModule=true 时，各功能模块可作为独立 App 运行，自带 mock 数据源，无需后端，便于单模块开发与调试。

注意事项：
- 提交态必须保持 isModule=false（集成构建），否则会破坏整体依赖关系
- 临时切换为 true 仅用于本地单模块调试，完成后务必改回 false
- 不要使用命令行 -PisModule=true 覆盖，以免渗透进 includeBuild 配置导致冲突

适用场景：
- 单独调试某个功能模块（如书架、书城、个人中心）
- 快速验证 UI/交互改动，无需装配完整应用

## 常见问题排查
- 无法解析依赖或同步失败
  - 检查网络与代理；settings.gradle.kts 已配置多个镜像源，必要时调整顺序或更换网络
  - 清理缓存后重试：./gradlew clean 并重新 Sync

- 构建失败提示工具链/JDK 问题
  - 确认 Android Studio 自带 JDK 17；避免手动指定不一致的 JDK 路径
  - 首次构建会由 Gradle 自动管理 toolchain

- 模拟器/真机无法连接后端
  - 检查 local.properties 的 ebook.server.host 是否指向正确地址
  - 真机建议用 adb reverse 将端口映射到 127.0.0.1，再配置 host 为 127.0.0.1
  - 注意 Android 17 对“本地网络”访问的限制，避免未授权导致请求被拒

- 权限相关异常（前台服务、网络等）
  - 清单已最小化声明必要权限；如遇 OEM 定制 ROM 差异，请在设备日志中定位具体权限缺失项
  - 涉及前台服务的行为与限制以 ADR 为准，遵循统一启动方式

- 模块独立运行时报路由找不到
  - 独立模式下跨模块路由不会生效；需要占位路由或测试宿主以模拟跳转链路

- 混淆与 Release 构建
  - release 开启混淆；如需排查崩溃，查看 mapping.txt 与日志堆栈
  - 规则以 consumer-rules.pro 为主，新增反射面需补充对应规则
