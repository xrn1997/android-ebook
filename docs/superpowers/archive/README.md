# 归档：已完成 / 已废弃的过程工件

本目录只存放经过价值筛选的已完成/已废弃 plans/specs。纯施工记录、已被现行事实源覆盖且无独有内容的工件在归档前删除；进入本目录的工件只作历史证据，**不是事实源**，提交后正文永久冻结：

> 2026-10-21 的首批归档先整体迁入、再在首次提交前按价值筛选；筛选后提交的 3 份才进入永久冻结。

- 不编辑、不删除（除非涉及敏感信息）。
- 需要新决策时，写新计划/新 ADR，或在现行事实源（[`docs/architecture.md`](../../architecture.md)、[`docs/adr/`](../../adr/)、[`docs/specs/`](../../specs/)）里更新。
- 归档文件开头的 `状态` 行说明归档原因与现行事实源；正文里的勾选框不代表待办。
- 链接入归档文件用于溯源是允许的，但不要把它当作当前行为的依据。

目录：

- [`plans/`](plans/) — 已落地的施工计划
- [`specs/`](specs/) — 已实现/被取代的变更设计、旧规格

放置与生命周期规则见 [`docs/AGENTS.md`](../../AGENTS.md)。
