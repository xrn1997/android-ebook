# 空态与失败态统一到本仓的 EmptyState，不用 lib_common 的位图插画

全仓的「空态」与「取不到内容的失败态」统一成一个共享组件 `EmptyState`（`lib_book_common` 的
`com.ebook.common.ui`）：线性图标 + 主文案 + 副文案 + 可选动作。**本仓不再使用** `lib_common` 现成的
`NoDataView`——它是唯一的事实源，还是本仓刻意不用的那个，两件事都得写清楚。

## 背景

同一件事在各页原本有四五种写法，差异全是从"各写各的"长出来的，不是设计：

- **空态两个流派**：`lib_common` 的 `NoDataView` 是一张 3D 彩色位图插画（`no_data.png`，356×363，
  xxhdpi 唯一一份、不随主题着色），而下载管理页的私有 `EmptyState` 是单色线性矢量图标（48dp + 60% 透明）。
  相邻两个页面，一个插画一个图标。
- **位图里烤死了文案**：`no_data.png` 画面底部印着「没有任何数据」四个字，而 `NoDataView` 还会在
  图片下方再渲染调用方给的 `title` 与 `hint`——同屏三层文字，第一层是写死的通用文案，关不掉。
- **主文案字号摇摆**：`NoDataView` 用 `titleMedium`（16sp），下载管理的私有件用 `bodyLarge`（16sp 但语义不同档）。
- **失败态三种重试控件**：详情页是"整行文字可点、没有按钮"，下载中心是 `TextButton`，
  阅读器是自绘胶囊。文案也三套：「加载失败，点击重试」/「加载失败，请重试」/「获取数据失败！」。

## 决策

1. **空态与失败态共用一个组件**。二者的结构完全同构（图标 + 主文案 + 副文案 + 可选动作），
   差别只有文案与图标；设两个组件就是让同样的"图标多大、文案什么字号"有两处可漂移。
2. **图标用线性单色、由调用方传入**，不在组件内按状态选。理由：共享库 `lib_book_common` 只允许依赖
   material-icons-core（体积由全部业务模块分担），而 `CloudOff`/`CloudSearchOff` 这类贴切图标在
   iconsExtended 里，只有业务模块有——把图标做成参数，两侧的依赖边界都不用破。
3. **位图插画在本仓退役**。`no_data.png` 这种"插画里印字 + 下面再给 title"的形态，
   文案重复且无法随主题着色；线性图标 + 语义色与全仓其余图标语言一致。
4. **动作槽要求文案与回调同时给出才渲染**。只给文案不给回调会画出一个点不动的按钮——
   这种写法编译期过得去、运行期静默失效，由组件挡下（`EmptyStateTest` 锁住）。
5. **副文案为空串不渲染**（不留空槽），沿用仓里「空字段不占位」的既有口径。

## 权衡

- **给 `NoDataView` 加动作槽、继续用它**：`NoDataView` 住在外部仓的 `lib_common`，
  它是全 `lib_common` 下游共用的件，改它等于让本仓的一次 UI 调整影响所有下游；
  而它"位图 + 图片自带文案"的形态是本仓要弃用的部分，改它就得连着换资产。故本仓自建。
- **保留位图插画、只统一字号**：改动最小，但两个流派的观感差异（彩色 3D 插画 vs 单色线性图标）
  远大于字号差异，用户一眼看到的是前者。
- **失败态另设一个 `ErrorState`**：结构同构、只有图标与文案不同，多一个组件就多一处可漂移的词汇表。

## 下游影响

- 新增 `lib_book_common` 的 `EmptyState` 与 `CommonUiTokens.stateIcon`（48dp）；
  同批把裸写的 `RoundedCornerShape(50)` 收成 `CommonUiTokens.pillShape`。
- 消费方改造：`module_book` 的书架（新增空态）、下载管理（删私有 `EmptyState`）、
  章节下载弹层（私有 `CenteredState` 的"书不在架/失败"两态改用共享件）、书籍详情（行内失败态）；
  `module_me` 的我的评论与书源管理（换掉 `NoDataView`）；`module_find` 书城的书源引导态
  （无源/坏源两档，原为自绘的 `SectionTitle` + 正文 + `TextButton` 块）。
- **阅读器豁免**：阅读器的加载/失败块画在"纸面"上，配色必须由 `ReadBookControl` 的正文色按透明度派生，
  套 Material 语义色会与四色纸张主题打架，故不接入 `EmptyState`。
- 加载态（无图标、只有转圈）不属于空态语义，不并入 `EmptyState`，留在各自调用点。
